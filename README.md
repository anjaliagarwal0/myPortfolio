# Anjali Agarwal Portfolio

A modern MERN Stack developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, lucide-react, and React Router DOM.

## Setup

1. Install dependencies

```bash
npm install
```

2. Start development server

```bash
npm run dev
```

3. Build for production

```bash
npm run build
```

4. Preview production build

```bash
npm run preview
```

## Project Structure

- `src/components/` — reusable UI components
- `src/pages/` — page views for Home, About, Projects, Contact
- `src/layouts/` — shared layout wrapper
- `src/data/` — placeholder portfolio data
- `src/index.css` — global Tailwind and custom styles
- `src/App.jsx` — router and page transitions

## Features

- Responsive mobile-friendly design
- Dark glassmorphism style with gradient accents
- Animated page transitions and card hover motion
- Active navigation highlighting
- Contact cards, education timeline, skills section, project cards
- No contact form, just contact details and links
